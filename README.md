# 🎬 Lion's Den Movie Theater

Lion's Den Movie Theater is a full-stack web and mobile application that allows users to browse movies, find nearby theaters, book tickets, and enjoy a seamless movie-going experience. The platform supports both users and administrators with tailored features, built with modern technologies including React, TypeScript, ASP.NET, and Firebase.

## 📱 Features

### 👤 User Features
- Browse latest and upcoming movies
- View detailed movie info and showtimes
- Locate nearby theaters using GPS
- Book and pay for tickets online (Stripe integration)
- View booking history and profile info
- Responsive mobile-first design (React Native)

### 🛠️ Admin Features
- Dashboard with key statistics
- Add, update, and delete movies and theaters
- Manage users and view chat logs
- Admin authentication and role-based access control

## 🧰 Tech Stack

| Layer        | Technology                          |
|--------------|--------------------------------------|
| Frontend     | React, TypeScript, Tailwind CSS, Vite |
| Backend      | ASP.NET Core 9, C#                     |
| Database     | SQL Server (for movies & users)      |
| Mobile App   | React Native, TypeScript, NativeWind |           |
| Payments     | Stripe API                           |
| Hosting      | Azure  |
